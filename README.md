## Accepted data-handling decisions

- Provide a confirmed **Delete local data** action in Settings. It removes local bills, payment and savings records, planets, game history, preferences, pending and delivered reminders, and app-owned backup copies, then returns to initial setup.
- Preserve Pro Lifetime store ownership and its verified entitlement cache. The reset does not refund a purchase or delete store/RevenueCat purchase records.
- Allow normal operating-system backups and migration, controlled by the user's device settings. CometDue has no financial-data backend or cloud-sync service.
- Explain that copies exported outside the app and existing device backups must be managed separately. Restoring an older backup may restore records previously deleted locally.
- Describe manual backups as readable JSON without app-level password protection or encryption.

## Behavior to document

- No CometDue accounts; financial and game records use an on-device database.
- Pro Lifetime is a one-time store purchase managed through RevenueCat. Purchase information is handled separately from local financial records.
- Local reminders may display bill details in notifications.
- Ordinary bill deletion preserves some history; the complete local reset is a separate action.
