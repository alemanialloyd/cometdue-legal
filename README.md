## Status

Planning is in progress. Legal policies have not yet been published, and GitHub Pages has not been enabled. This README is not a store privacy policy.

The planned app screens will be readable offline. Shared, versioned document content will also generate the public website.

## Behavior to document

- No CometDue accounts or financial-data backend; financial and game records use an on-device database.
- Pro Lifetime is a one-time store purchase managed through RevenueCat. Purchase information is handled separately from local financial records.
- Local reminders may display bill details in notifications.
- Manual backups are readable JSON files shared to destinations chosen by the user.
- Deleting a bill currently preserves some history; there is no complete local erase action yet.
- Current app configuration does not explicitly exclude data from operating-system backups.
